## 如何添加首页到菜单

由于 cool-admin 使用数据库管理菜单，需要在后台添加首页菜单：

### 方法1：通过后台管理界面添加（推荐）

1. 登录后台管理系统
2. 进入 **系统管理 -> 菜单管理**
3. 点击"新增"按钮
4. 填写以下信息：
   - **菜单名称**: 首页
   - **路由地址**: /home
   - **类型**: 菜单
   - **排序**: 1 (显示在最前面)
   - **图标**: 选择一个首页图标（如 home 或 house）
   - **是否显示**: 是
5. 保存后刷新页面

### 方法2：直接修改数据库

在数据库的 `base_sys_menu` 表中插入一条记录：

\`\`\`sql
INSERT INTO base_sys_menu (
  name, 
  path, 
  type, 
  icon, 
  orderNum, 
  isShow, 
  parentId
) VALUES (
  '首页',
  '/home',
  1,
  'home',
  1,
  1,
  NULL
);
\`\`\`

### 方法3：临时访问（开发测试用）

直接在浏览器地址栏访问：
\`\`\`
http://localhost:9001/#/home
\`\`\`

## 首页路由

- 路由路径: `/home`
- 组件位置: `src/modules/home/views/index.vue`
- 配置文件: `src/modules/home/config.ts`

## 注意事项

1. 首页需要后端API支持才能显示数据
2. 如果后端服务未启动，统计数据会显示"加载中..."
3. 数据列表在没有数据时会显示空表格
