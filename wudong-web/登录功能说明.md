## 🚀 使用方式

### 访问页面
http://localhost:3000

### 快速登录步骤

1. **访问任意需要登录的页面**
   - 点击"发布帖子"
   - 或访问"我的"
   - 自动跳转到登录页

2. **一键登录（推荐）**
   - 默认选中"快速登录（测试）"标签
   - 点击"一键登录"按钮
   - 自动登录并跳转

3. **账号密码登录**
   - 切换到"账号密码"标签
   - 输入任意用户名和密码
   - 点击"登录"按钮

4. **登录成功后**
   - 顶部显示用户头像
   - 可以发布帖子
   - 可以查看个人中心

## 📝 技术实现

### Token 存储
```javascript
// 存储
localStorage.setItem('token', 'test-token-xxx')
localStorage.setItem('userInfo', JSON.stringify(userInfo))

// 读取
const token = localStorage.getItem('token')
const userInfo = JSON.parse(localStorage.getItem('userInfo'))
```

### 请求拦截器
```typescript
// 自动添加 Token
config.headers.Authorization = token

// Token 失效处理
if (res.code === 1002 || res.code === 1001) {
  router.push('/login')
}
```

### 路由守卫
```typescript
router.beforeEach((to, from, next) => {
  if (to.meta.requiresAuth && !token) {
    next('/login?redirect=' + to.fullPath)
  }
})
```

## ⚠️ 注意事项

### 当前为测试模式
- 使用模拟 Token，非真实后端登录
- Token 格式：`test-token-[时间戳]`
- 用户信息为模拟数据

### 如需对接真实登录接口

修改 `src/views/Login.vue` 中的 `handleTestLogin` 和 `handleLogin` 方法：

```typescript
// 调用真实登录接口
const res = await request.post('/admin/base/open/login', {
  username: loginForm.value.username,
  password: loginForm.value.password
})

// 保存真实 Token
userStore.login(res.token, res.userInfo)
```
