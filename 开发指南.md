# 乌东文旅平台开发指南

## 环境准备

### 必备软件
- Node.js 18+
- MySQL 8.0
- Redis 7.0（可选）
- Git
- VSCode

### 克隆项目

```bash
git clone https://github.com/spapyllllx/wudong.git
cd wudong
```

## 后端启动

```bash
cd cool-admin-midway

# 1. 安装依赖
pnpm install

# 2. 配置数据库
# 编辑 src/config/config.local.ts
# 修改数据库连接信息

# 3. 启动项目
pnpm run dev

# 访问: http://localhost:8001
# Swagger文档: http://localhost:8001/swagger-ui
```

## 前端启动

```bash
cd cool-admin-vue

# 1. 安装依赖
pnpm install

# 2. 启动项目
pnpm run dev

# 访问: http://localhost:9000
# 默认账号: admin / 123456
```

## 分支管理

### 创建功能分支

```bash
# 1. 切换到develop分支
git checkout develop
git pull origin develop

# 2. 创建你的功能分支
git checkout -b feature/你的模块名

# 例如：
git checkout -b feature/clothing-module  # 商品模块
git checkout -b feature/food-module      # 餐饮模块
```

### 提交代码

```bash
# 1. 查看修改
git status

# 2. 添加文件
git add .

# 3. 提交（注意提交规范）
git commit -m "feat: 完成商品列表功能"

# 4. 推送到远程
git push origin feature/你的分支名
```

### 发起Pull Request

1. 访问 https://github.com/spapyllllx/wudong
2. 点击 "Pull requests" -> "New pull request"
3. 选择：`feature/你的分支` → `develop`
4. 填写PR描述，提交
5. 等待组长审查

## 开发流程

### 1. 后端开发示例（以商品模块为例）

#### 步骤1：创建Entity

```typescript
// src/modules/clothing/entity/product.ts
import { Entity, Column } from 'typeorm'
import { BaseEntity } from '@cool-midway/core'

@Entity('products')
export class ProductEntity extends BaseEntity {
  @Column({ comment: '商家ID' })
  merchant_id: number
  
  @Column({ comment: '商品标题' })
  title: string
  
  @Column({ type: 'decimal', precision: 10, scale: 2, comment: '价格' })
  price: number
  
  @Column({ type: 'int', default: 0, comment: '库存' })
  stock: number
}
```

#### 步骤2：创建Service（可选，简单CRUD可省略）

```typescript
// src/modules/clothing/service/product.ts
import { Provide } from '@midwayjs/decorator'
import { BaseService } from '@cool-midway/core'
import { InjectEntityModel } from '@midwayjs/typeorm'
import { Repository } from 'typeorm'
import { ProductEntity } from '../entity/product'

@Provide()
export class ProductService extends BaseService {
  @InjectEntityModel(ProductEntity)
  productEntity: Repository<ProductEntity>
  
  // 自定义业务方法
  async getHotProducts(limit: number = 10) {
    return await this.productEntity.find({
      where: { status: 'on_sale' },
      order: { sales: 'DESC' },
      take: limit
    })
  }
}
```

#### 步骤3：创建Controller

```typescript
// src/modules/clothing/controller/app/product.ts
import { Provide } from '@midwayjs/decorator'
import { CoolController, BaseController } from '@cool-midway/core'
import { ProductEntity } from '../../entity/product'

@Provide()
@CoolController({
  api: ['add', 'delete', 'update', 'info', 'list', 'page'],
  entity: ProductEntity,
  pageQueryOp: {
    keyWordLikeFields: ['title']
  }
})
export class AppProductController extends BaseController {}
```

### 2. 前端开发示例（uni-app小程序）

```vue
<!-- pages/product/list.vue -->
<template>
  <view class="product-list">
    <view v-for="item in products" :key="item.id" class="product-item">
      <image :src="item.main_image" />
      <text class="title">{{ item.title }}</text>
      <text class="price">¥{{ item.price }}</text>
    </view>
  </view>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import { getProductList } from '@/api/product'

const products = ref([])

onMounted(async () => {
  const res = await getProductList({ page: 1, pageSize: 10 })
  products.value = res.data.list
})
</script>
```

## 常见问题

### Q1: 数据库连接失败？
A: 检查 `src/config/config.local.ts` 中的数据库配置是否正确

### Q2: 端口被占用？
A: 修改端口配置或关闭占用端口的进程

### Q3: 依赖安装失败？
A: 尝试删除 `node_modules` 和 `pnpm-lock.yaml`，重新安装

### Q4: Git冲突怎么办？
A: 联系组长，一起解决冲突
